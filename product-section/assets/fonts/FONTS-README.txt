Ram Investments Diary 2027 - fonts
==================================

Two fonts, both free under the SIL Open Font License 1.1 (commercial printing
allowed). Licence texts: OFL-AnekLatin.txt and OFL-Mukta.txt.

1. Mukta - body text, tables, notes, legal lines
   Mukta-Regular, -Medium, -SemiBold and -Bold are used; Light and ExtraBold
   are included for completeness.

2. Anek Latin - headings, page titles, labels, running heads, numbers
   AnekLatin[wdth,wght].ttf is a variable font: one file with every width and
   weight. Use it in InDesign, Illustrator, Affinity or CorelDRAW 2020 and newer.

   For software without variable-font support (for example CorelDRAW 2019 or
   older), install the files in anek-latin-static/. They are fixed copies of the
   exact width and weight combinations the diary uses, all in one family,
   "Anek Latin Print". Each file name gives the width, then the weight:

     Condensed 700        width 75%,   weight 700
     SemiCondensed 550    width 87.5%, weight 550
     SemiCondensed 600    width 87.5%, weight 600
     SemiCondensed 650    width 87.5%, weight 650   (most labels and small caps)
     SemiCondensed 700    width 87.5%, weight 700
     Width92 700          width 92%,   weight 700
     Width95 750          width 95%,   weight 750
     Normal 650           width 100%,  weight 650
     Normal 700           width 100%,  weight 700
     Width108 700         width 108%,  weight 700   (page titles)
     Width108 750         width 108%,  weight 750   (welcome page firm name)
     Width115 750         width 115%,  weight 750

   Both fonts are also on Google Fonts (fonts.google.com).
